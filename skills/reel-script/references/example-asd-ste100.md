# Worked example: ASD-STE100 (141 words, 44.8 s at 1.15x)

| Beat | Line | Picture |
|---|---|---|
| Hook | This one line changed the way I prompt AI. | Face. "Explain this in ASD-STE100." typed in a pill |
| Origin | It comes from aircraft repair manuals and even Andrej Karpathy uses it. | USAF maintenance footage, Karpathy clip, credits |
| Proof | Ask your AI to explain something in ASD-STE100. It's a writing standard with short sentences and a fixed list of approved words. | Karpathy's post with highlights, chart callouts |
| How | I asked the same question twice. What is a race condition? | Prompt pair |
| Result | The normal answer on the left is 2,400 characters. The ASD-STE100 answer on the right is 1,300 with the same facts. | Scroll cards, then bars |
| Catch | But there's a catch. If you follow it strictly, the answer tells you what to do but not why. | Face punch-in, "The catch" stamp, then a strictness verdict card |
| My test | I used it to rewrite the plan for the channel. It said cut 20% of the script but never said why. | Chat card, "Why?" stamp |
| Fix + CTA | So Karpathy softened it. He asks for 80% of the way to ASD-STE100. If someone you know skips long AI answers, send this to them. | Karpathy clip, quote card, face |

Why it works: the hook is a personal claim, proof arrives by second 6, there is one number, the catch is honest, and the CTA names who to send it to.
